# GBK 编码样例

这份文件**不是 UTF-8**，而是用 GBK 编码保存的，用来验证「按 GBK 打开」的入口。

## 该看到什么

用阅读器打开这份文件时，应当先弹出一条提示，说明它不是 UTF-8 编码，并给出「按 GBK 打开」按钮。

点一下按钮，下面的中文应当正常显示（不是问号、不是方块、不是乱码）：

- 简体中文排版测试：这是一个用 GBK 编码保存的 Markdown 文档。
- 标点与全角字符：，。！？；：「」『』（）——……
- 生僻一点的字：饕餮、魑魅魍魉、犇、猋、骉
- 混合排版：Markdown 与中文混排时，English 与汉字应当都能读。

## 记住选择

点过一次之后，编码选择会被记住。关掉再打开同一份文件，应当直接进入正常内容，不再弹提示。

标题栏的文件名右边会显示一个 `GBK` 标记，表明当前是用转码后的内容在阅读。

## 代码高亮

GBK 文件里的代码块同样要能高亮：

```python
def 问候(名字):
    print(f"你好，{名字}！")  # GBK 文件里的中文注释
    return True
```
